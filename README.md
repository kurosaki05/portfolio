# 黒﨑日都美 Portfolio

システムエンジニア 黒﨑日都美のポートフォリオサイトです(日英併記)。
Portfolio site of Hitomi Kurosaki, Systems Engineer (Japanese / English).

## 構成 / Structure

- `index.html` — ページ本体。HTML・CSS・JavaScript を 1 ファイルにまとめています。ビルドは不要です。

## 表示方法 / How to view

`index.html` をブラウザで開くだけで表示できます。
GitHub Pages で公開する場合は、リポジトリの Settings → Pages で公開元に `main` ブランチのルートを選びます。
